# Privacy Policy — My Discord Drive Bot

**Last updated:** 19/10/2025

## 1. Introduction
My Discord Drive Bot ("the bot") is designed to interact with Google Drive on behalf of users. It helps users upload, download, and manage files in Google Drive.

## 2. Data We Collect
- **OAuth tokens / authorization data:** The bot stores refresh and access tokens to perform actions on Google Drive for the user.
- **Discord account information:** User ID or server ID is only used to link bot activity to accounts.
- **Metadata:** Basic file information (e.g., file name, timestamps) to track uploads and downloads.

## 3. How We Use Data
Collected data is used solely to:
- Upload or download files to/from Google Drive as requested by the user.
- Manage file metadata linked to user accounts.
- Handle bot operations such as backups or file retrieval.

## 4. Data Sharing
The bot **does not sell or share personal data with third parties**. Data may only be shared with:
- Google (via API) when needed to perform requested operations.
- Legal authorities if required by law.

## 5. Storage & Security
- Tokens and metadata are stored securely on the host server.  
- Encryption and access control are used to protect sensitive data.  
- Users can request deletion of all stored data via support.

## 6. User Rights
Users can:
- Request deletion of their data.
- Revoke OAuth access (via Google or disconnecting the bot).  
- Review the data the bot stores.

## 7. Google Scopes Used
The bot requests the following scopes:
- `https://www.googleapis.com/auth/drive.file` (or `https://www.googleapis.com/auth/drive` for full access)  
These scopes are used **only for file upload/download operations** on behalf of the user.
